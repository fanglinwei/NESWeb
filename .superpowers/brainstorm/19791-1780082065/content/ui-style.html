UI 风格方向 — 二次元像素可爱风

NES 本身就是 8-bit 像素美学的代表，加上二次元可爱元素让整体更有个性

A

霓虹像素风 🎀

深色底 + 霓虹粉/紫渐变边框，像素字体标题，发光按钮。类似 8-bit 音乐游戏风格，酷中带可爱。

B

软萌像素风 🍰

C

复古掌机风 🕹

模拟 Game Boy / GBA 硬体质感，灰白机身配色 + 彩色按钮点缀，按钮做成实体按压感，像一个专门的游戏机。
