Main Emulator Screen

来自 pages/main-emulator-screen.md：游戏画面优先、画布不变形、辅助 UI 不遮挡核心内容。

Canvas first

  • 居中显示游戏画布
  • 保持 NES 宽高比
  • 不要裁剪或拉伸 gameplay

Tactile frame

  • 暗色街机外框
  • 低透明度红/蓝径向光
  • 轻量阴影，不干扰游戏

Accessible states

  • 加载/暂停/错误状态靠近画布
  • 状态变化使用 aria-live
  • 颜色含义配合文字说明

Floating Controls

来自 pages/floating-controls.md：分组、触控友好、SVG/vector 图标优先、每个 icon-only 按钮都要有可访问名称。

Toolbar shell

半透明深色 pill 容器，明显边框、内高光和轻微 elevation。重置等危险操作需要视觉分离。

Settings Modal

来自 pages/settings-modal.md：强遮罩、暗色 elevated surface、清楚分组、危险操作独立 danger zone。
