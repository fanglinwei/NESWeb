Documented Rules

  • Toolbar uses one grouped pill container.
  • Icon-only actions have aria-label and visible hover/focus tips.
  • Reset uses destructive color and spacing separation.
  • Normal touch targets are 44x44px.

Accessibility Pass

  • Tab order follows visual group order.
  • Dividers are aria-hidden.
  • Pause state uses aria-pressed.
  • Reduced motion removes decorative lift.
